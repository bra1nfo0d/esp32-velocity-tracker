# Geschwindigkeitssensor für Krafttraining mit ESP32

Ein Gerät mit ESP32 und 3-Achsen-Beschleunigungssensor (Adarfruit ADXL343), das an der Hantel befestigt wird. Es zeigt den Beschleunigungsverlauf und zählt die Wiederholungen pro Satz. Dazu berechnet es Hubweg (ROM), Geschwindigkeit (v_peak, MCV) und den Geschwindigkeitsverlust im Satz.

*Projekt im Modul "Projekt: Embedded Systems, IoT, SmartX" der FOM.*
